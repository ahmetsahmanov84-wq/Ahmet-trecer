PERSONAL KPI TRACKER 1.0.1

Файлы: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png, favicon.png.

Установка через GitHub Pages:
1. Создайте публичный репозиторий на GitHub.
2. Загрузите все файлы из архива в корень репозитория, заменив старые.
3. Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
4. Откройте опубликованный HTTPS-адрес в Safari на iPhone.
5. Поделиться -> На экран «Домой».
6. После первого полного открытия с интернетом приложение кэширует файлы и работает офлайн.

Внимание: данные сохраняются локально на конкретном устройстве в IndexedDB. Регулярно экспортируйте JSON из Настроек. CSV подходит для просмотра в Excel, но не для восстановления приложения.

Отбой: из-за закрытия дня в 00:00 задача сна отмечается заранее (как готовность ко сну), фактическое засыпание не определяется автоматически.

Обновление иконки: после загрузки новых файлов перезапустите приложение. Если iOS сохраняет прежнюю иконку на экране Домой, удалите старый ярлык и добавьте сайт на экран Домой повторно. Данные могут быть привязаны к установленному приложению, поэтому перед удалением обязательно экспортируйте JSON-резервную копию.
